# Conference Frontend
Front-end code sample for the [Conference REST API](https://github.com/arturomorarioja/py_conference_api) using performance best practices:
- Parallel asynchronous requests
- ES modules
- Dynamic `import()`
- `<template>`
- `DocumentFragment`
- Safe text insertion
- Responsive WebP assets
- Reserved image dimensions
- Lazy-loading images 
- Non-blocking decorative CSS
